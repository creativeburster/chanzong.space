## 📌 一、 为什么要做“禅宗数字人文知识图谱”？

禅宗作为中国思想史与东方哲学中极具特色的智慧流派，其传法以“不立文字，教外别传，直指人心，见性成佛”著称。然而，在其两千多年的历史演变中，沉淀下了极其浩瀚的文献体系——从早期的《达摩四行观》、《血脉论》，到中期的《六祖法宝坛经》、《永嘉证道歌》，再到宋代极度繁盛的《无门关》、《碧岩录》百则公案颂古。

在传统的典籍查阅中，参学者常面临三大痛点：
1. **文献孤立**：传统古籍往往单本印刷，读者很难直观获知某位祖师（如黄檗希运）在整个禅宗五家七宗谱系中的法脉上下承接；
2. **名相断层**：禅宗特有的核心概念（如“转识成智”、“无门”、“心王”、“本来面目”）往往散落在不同典籍中，缺乏全网状关联；
3. **数字化质量参差不齐**：网络上流通的 OCR 电子书充斥页眉页脚乱码与错别字，缺乏现代白话精准导学。

为此，我们发起了非营利项目“禅宗知识库”，旨在用现代数字人文（Digital Humanities）技术，构建一个多维互链、交互式物理仿真的全球禅门知识体系。

## 🛠️ 二、 核心技术架构与工程实现

本项目采用现代全栈前端技术栈构建，全面兼顾性能、SEO 友好度与极致的交互美学：

```text
├── Next.js 14 (App Router)  // 混合服务端渲染 (SSR) 与客户端水合 (Hydration)
├── React 18 + TypeScript    // 强类型知识分类拓扑 (taxonomy.ts)
├── Tailwind CSS             // 温润宣纸水墨视觉风格 (#FAF9F6 / #0F172A)
├── D3.js v7 力导向物理引擎    // 交互式知识图谱力模拟与碰撞衰减
└── PWA Service Worker       // 全站离线缓存与无网参修支持
```

### 1. D3.js v7 力导向交互物理引擎

在 GraphCanvas 核心组件中，我们将 40+ 部经典、60+ 历代祖师、160+ 核心概念与 205+ 则公案机锋抽象为异构拓扑网络：

```typescript
// 节点分类与配色规范
const colorMap: Record<string, string> = {
  center: "#D97706",    // 中心正法 (金色)
  person: "#2563EB",    // 祖师人物 (禅青)
  classic: "#DC2626",   // 核心经典 (朱砂)
  concept: "#059669",   // 核心概念 (翠绿)
  method: "#7C3AED",    // 修持法门 (紫檀)
  qa: "#4B5563"         // 机锋问答 (墨灰)
};

// 物理仿真配置与阻尼防抖
const simulation = d3.forceSimulation(nodes)
  .force("link", d3.forceLink(links).id((d: any) => d.id).distance(80))
  .force("charge", d3.forceManyBody().strength(-200))
  .force("center", d3.forceCenter(width / 2, height / 2))
  .force("collision", d3.forceCollide().radius(25));

// 运行 3 秒后自动冻结以彻底消除性能损耗与抖动
setTimeout(() => {
  simulation.stop();
}, 3000);
```

### 2. 网状多卡片交叉互链网络 (Card Interlinking)

为了打破传统文献的孤岛状态，全站任何详情页均设计为无死角全网状卡片互链：
- 在阅读《六祖坛经》时，侧边栏与文末动态聚合出关联祖师（惠能、弘忍、神秀）、关联概念（自性清净、顿悟、无念无相无住）与关联公案；
- 形成真正的“全网状互链拓扑”，极大地增强了搜索引擎蜘蛛的深层抓取效率与用户研读体验。
